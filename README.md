
# Telegram Smetana Utilities 

Утилита для Telegram-бота, работающего через **Business Connections**.  
Бот обрабатывает сообщения в бизнес-чатах, предоставляет набор AI-инструментов, конвертеров, работу с медиа и автоматический ответчик, когда владелец аккаунта долго молчит.

---

## ✨ Возможности

- **AI-инструменты (LLM7)** — генерация ответов, перевод, анализ настроения, определение времени в городе.
- **Медиа** — скачивание видео/аудио по ссылке (через `yt-dlp`), распознавание голосовых сообщений (`SpeechRecognition` + Google API).
- **Утилиты** — конвертация валют и единиц измерения, погода, сокращение ссылок.
- **Автоответчик** — если владелец бизнес-аккаунта молчит дольше заданного времени, бот отвечает собеседнику автоматически.
- **Плагины** — динамическая подгрузка модулей из папки `plugins/`.
- **Статистика** — подсчёт сообщений в чате.

---

## 🚀 Запуск

```bash
python tg_utilits.py
```

При старте бот:
1. Загружает плагины из папки `plugins/` (создаётся автоматически).
2. Подписывается на `business_connection`, `business_message`.
3. Запускает `infinity_polling`.

---

## 🧩 Плагины

Для добавления своей команды создайте файл `plugins/my_plugin.py`:

```python
def run(bot, **config):
    @bot.business_message_handler(content_types=['text'])
    def handler(message):
        if message.text == '.hello':
            bot.send_message(
                message.chat.id,
                'Привет!',
                business_connection_id=message.business_connection_id,
            )
```

Все переменные из `config.py` доступны как keyword-аргументы функции `run`.  
Каждый плагин **обязан** иметь функцию `run`.

## 🕹 Команды

Все команды пишутся в бизнес-чат и начинаются с точки (`.`).  
Команды, работающие «ответом на сообщение», требуют **реплая**.

### 🧠 AI и перевод
| Команда | Описание |
|---|---|
| `.ai <запрос>` | Ответ от LLM7 |
| `.translate <язык>` | Перевести сообщение, на которое отвечают |
| `.mood` | Анализ настроения сообщения |
| `.time <город>` | Текущее время в городе (через LLM) |

### 🎬 Медиа
| Команда | Описание |
|---|---|
| `.download <url>` | Скачать видео/аудио по ссылке (до 2 ГБ) |
| `.audio <url>` | Скачать только аудио (mp3) |
| `.recog` | Распознать голосовое (ответом на voice) |

### 🛠 Инструменты
| Команда | Описание |
|---|---|
| `.convert 100 USD RUB` | Конвертация валют (USD/EUR/RUB) и единиц (KM/MI, KG/LB) |
| `.weather <город>` | Погода (Open-Meteo) |
| `.short <url>` | Сократить ссылку (TinyURL) |

### ℹ️ Прочее
| Команда | Описание |
|---|---|
| `.stat` | Статистика сообщений в чате |
| `.help` / `/help` | Справка |

## 🤖 Автоответчик

Логика:
1. Когда **владелец** пишет в чат — фиксируется время его последнего сообщения.
2. Когда **собеседник** пишет, а с последнего сообщения владельца прошло больше `AUTOREPLY_TIMEOUT_MINUTES` — отправляется автоответ.
3. Повторный автоответ **не отправится**, пока владелец снова не напишет в чат.

> Автоответчик не активируется, если владелец ни разу не писал в этот чат.

## 🔒 Замечания по безопасности

- Не храните `config.py` с токенами в публичном репозитории — добавьте его в `.gitignore`.
- Файл `tg_utilits.py` содержит словари состояния (`connection_owners`, `owner_last_message`, `autoreply_last_sent`) **в памяти**. После перезапуска данные теряются.
- Ограничение Telegram — файлы до **2 ГБ**; бот проверяет размер и отказывается отправлять слишком большие.

---

## 🐛 Известные ограничения

- Распознавание речи использует Google Speech API — требуется доступ в интернет.
- `yt-dlp` может не работать на некоторых хостингах из-за блокировок (используйте `PROXIES`).
- Автоответчик полагается на `business_connection_id`, поэтому работает **только** в бизнес-чатах.
